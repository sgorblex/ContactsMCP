# Claude (and similar clients)

Follow **[`AGENTS.md`](AGENTS.md)**: read it before implementing. It carries the conventions and
the *After you change the repository* table.

**Git / Graphite:** `gt` is this repository's standard for branching and stacking; check the
current stack (`gt log short`) before adding branches. **Never push, `gt submit`, open, merge or
comment on a PR, or run any other remote-mutating command unless the user explicitly asks for
that in the current request.**
